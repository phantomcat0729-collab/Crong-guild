📖 쿠폰 사용방법

1. 인게임에서 사용하는 방법 (AOS / PC버전)

게임 접속 [메뉴 - 환경 설정(⚙️) → 기타 → 쿠폰] 버튼 선택 후 쿠폰 번호 입력

※ 인게임 [쿠폰] 기능은 안드로이드 기기에서만 가능합니다.

※ 안드로이드 기기가 아닌 다른 기기를 이용하실 경우 아래 공식 홈페이지(쿠폰함)을 이용 부탁드립니다.

2. 공식 홈페이지(쿠폰)에서 사용하는 방법 (IOS / 모든 기기)

🎟️ 쿠폰 바로가기

[쿠폰 바로가기]에서 회원번호(UID)와 함께 쿠폰 번호를 입력하면 끝!

※ 회원번호(UID)는 게임 내 [환경 설정] → [계정] 에서 확인할 수 있으며 [복사] 기능을 사용할 수 있습니다.

✅ 회원코드 확인 방법

게임 내 메뉴 → 환경 설정(⚙️) → [계정] 탭 → 'UID' 복사
